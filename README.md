# Visualizador de Árboles Binarios

Herramienta interactiva para **Matemática Discreta** / Estructuras de Datos.

## Qué hace
- Construye **árboles binarios de búsqueda (BST)** o árboles que se llenan por niveles.
- Muestra recorridos **Inorden**, **Preorden** y **Posorden**.
- Anima el recorrido paso a paso.
- Dibuja el árbol con el orden de visita en cada nodo.

## Cómo usarlo
1. Abre el archivo [`index.html`](index.html) en el navegador, **o**
2. Activa GitHub Pages (Settings → Pages → Source: Deploy from a branch → main / root).
